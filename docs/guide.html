대시보드 가이드

로컬 빌드, 외부 JSON 업로드, 자연어 질의 라우팅, GitHub Pages 배포까지 한 번에 따라가기 위한 요약 가이드다.

1. 데이터 빌드

npm run build:dashboard

`exports/core-db/*.csv`를 읽어 `docs/data/dashboard-data.json`과 `docs/data/import-template.json`을 생성한다.

2. 메타데이터 DB 빌드

npm run build:metadata

FISIS, ECOS, KRX, INCOS, KOFIA 메타데이터를 실제 호출해 `exports/metadata`와 `docs/data/metadata-db.json`에 저장한다.

3. 로컬 미리보기

npm run serve:dashboard

기본 주소는 http://127.0.0.1:4173다.

4. 자연어 질의 라우터

  • 질문을 입력하면 후보 소스와 지표를 추천한다.
  • 현재는 규칙 기반 카탈로그 방식이며, 후속 단계에서 실제 API 메타데이터 DB와 연동한다.
  • 예: `국내 은행 이자수익과 KOSPI 지수 추이 비교해줘`

5. 메타데이터 탐색기

  • `docs/data/metadata-index.json`을 읽어 실제 기관 메타데이터를 검색한다.
  • 검색 결과에서 소스/코드/분류를 확인한 뒤 바로 대시보드 검색 조건으로 넘길 수 있다.

7. 다운로드

  • 선택한 시리즈를 CSV로 다운로드할 수 있다.
  • 동일 비교 테이블을 Excel 호환 `.xls`로 내릴 수 있다.
  • 선택 시리즈 전체를 JSON으로 저장할 수 있다.

8. GitHub Pages 배포

  • 방법 A: `.github/workflows/deploy-pages.yml` 사용
  • 방법 B: GitHub Pages에서 branch=`main`, folder=`/docs` 선택

9. 배포 전 체크

npm test
npm run check
